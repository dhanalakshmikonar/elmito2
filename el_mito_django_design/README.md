# EL MITO APPARELS

Django storefront retaining the EL MITO editorial frontend and using the existing EL MITO ecommerce backend for catalogue, customer accounts, cart, checkout, orders, inventory and Razorpay payments.

## Local development

1. Create and activate a virtual environment.
2. Install `requirements.txt`.
3. Copy `.env.example` to `.env`; set a local secret and SMTP/Razorpay test credentials as needed.
4. Run `python manage.py migrate`.
5. Run `python manage.py runserver` and open `http://127.0.0.1:8000/`.

The admin at `/admin/` manages categories, product records, multiple product images, size/colour variants, stock, campaign flags and order status. Catalog items are shown from their uploaded media; no sample product photos or product records are generated by the frontend.

## Deployment configuration

Configure `SECRET_KEY`, `DEBUG=False`, `ALLOWED_HOSTS`, `CSRF_TRUSTED_ORIGINS`, `DATABASE_URL`, `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET`, `RAZORPAY_WEBHOOK_SECRET` and SMTP settings in the host environment. Media uses Django filesystem storage. To include existing product photos on Render, commit the files under `media/categories/` and `media/products/` with the same paths referenced by product records. Local product/category database records do not sync to Render. Render free filesystems are ephemeral, so media uploaded through the live admin can be lost after a restart or deploy; keep source copies in the repository and redeploy them with the site. Run migrations as part of deployment. Shipping is configured at ₹0.

Never commit `.env` or payment secrets.
